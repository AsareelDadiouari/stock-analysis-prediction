# Stock Analysis & Prediction

> 🚧 **In development**

A tool that pulls market data, runs technical analysis on stocks and experiments with
machine-learning models to forecast price trends, with interactive charts to explore the results.

## Planned features

- **Market data ingestion** — historical prices and volumes for a chosen list of tickers
- **Technical analysis** — moving averages, RSI, MACD, Bollinger Bands and more
- **Forecasting experiments** — compare statistical and machine-learning models against a baseline
- **Backtesting** — measure how predictions would have performed on past data
- **Interactive charts** — explore prices, indicators and forecasts side by side

## Tech stack (planned)

| Area          | Technology                       |
| ------------- | -------------------------------- |
| Data & models | Python, pandas, scikit-learn     |
| Interface     | Angular                          |
| CI/CD         | GitHub Actions                   |

## Branches

- `main` — stable releases
- `develop` — integration branch; features are merged here first

## Disclaimer

This is a personal learning and research project. Nothing it produces is financial advice,
and its predictions should not be used to make investment decisions.
